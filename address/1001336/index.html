Liquor license fields. The ID is SLA's own: license_permit_id (inactive). Type and class are the datasets' type and class columns, shown as the dataset has them; the words are description. The active-license dataset writes classes with a leading zero (0370); the pending and inactive datasets, SLA's class sheet and LAMP write the same class without it (370). See SLA license type and class definitions (Excel file).

LAMP link. "Show on the SLA's LAMP map" opens SLA's LAMP map centered on the license's point, at zoom 18. It opens a map location, not the license record. LAMP first shows a welcome box; close it. LAMP places each license at its own point, which can differ from this one: when we compared (2026-11-04), most were within about 13 m, but 145 of 2,344 were more than 50 m away, and LAMP shows no pin for "Additional Bar" permits. Check that the pin you click has the same license ID. When we checked (2026-11-04), SLA's LAMP popup listed premises and license details, principals and disciplinary history, and several licenses at one spot are paged ("1 of 6"). The point is the dataset's georeference, which the data.ny.gov platform geocodes from the address ("Open Data platform-generated geocoding information from supplied address components. Point-type location is the centroid of the address components provided and does not reflect a specific address if the street address component is not provided."). It is not SLAM's geocode. A license with no point has no link.

Hours and method of operation. The SLA open data does not include method of operation or hours, and neither did the LAMP popup when we checked. Approval conditions for contested applications, which can include closing hours and community board stipulations, appear in the minutes of SLA's Full Board meetings; each meeting's page in the SLA event calendar links its minutes once they are posted after the meeting.

The rule these distances relate to

New York Alcoholic Beverage Control Law §64(7) sets a 200-foot rule about schools and places of worship and a 500-foot rule about three or more existing on-premises licensed premises, measured entrance to entrance. SLAM measures building point to building point, so every distance here is approximate. This page does not decide whether a rule applies; the State Liquor Authority makes that decision.
