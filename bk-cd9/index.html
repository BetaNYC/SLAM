Liquor license fields. The ID is SLA's own: application_id (pending), licensepermitid (active). Type and class are the datasets' type and class columns, shown as the dataset has them; the words are description. The active-license dataset writes classes with a leading zero (0370); the pending and inactive datasets, SLA's class sheet and LAMP write the same class without it (370). See SLA license type and class definitions (Excel file).

Dates and other IDs. Each is a column of SLA's open data, shown as published when the license has a value. Last issued (renewal) is lastissuedate ("Last Issue Date", described as "Renewal Date"); Effective is effectivedate ("Effective Date"); Legacy serial number is legacyserialnumber ("Legacy Serial Number", described as "Previous Serial Number"); Parent license is parentlicenseid ("Parent License ID"); AKA address is aka_address, akaaddress ("AKA Address"). Pending applications have none of these except the AKA address; the inactive-license dataset has no parent license column. In the active list on 2026-11-07, the parent license ID was filled in only for additional bar permits (all 1,842 of them), and names another license.

Open this license in LAMP. This link opens SLA's LAMP map on the license's own record, found by its ID. It uses a setting inside LAMP's map that SLA could change; each SLAM build checks that setting and leaves the link out if it no longer holds. It worked for an active, a pending and an inactive license on 2026-11-05.

LAMP map link. "Show on the SLA's LAMP map" opens SLA's LAMP map centered on the City's address point for the building when SLAM matched the address, otherwise on the point in SLA's open data, at zoom 18. (The open data's points come from data.ny.gov's own geocoding and can be blocks off for Queens addresses written without the hyphen; LAMP's own pins were within about 200 ft of the City's point when we checked on 2026-11-05.) It opens a map location, not the license record. LAMP first shows a welcome box; close it. LAMP places each license at its own point, which can differ from the link's center. Against SLA's open-data points (2026-11-04), most LAMP pins were within about 13 m, but 145 of 2,344 were more than 50 m away; against the City's address point we have checked only four Queens licenses (2026-11-05), whose LAMP pins were 92 to 203 ft away. LAMP shows no pin for "Additional Bar" permits. Check that the pin you click has the same license ID. When we checked (2026-11-04), SLA's LAMP popup listed premises and license details, principals and disciplinary history, and several licenses at one spot are paged ("1 of 6"). The point is the dataset's georeference, which the data.ny.gov platform geocodes from the address ("Open Data platform-generated geocoding information from supplied address components. Point-type location is the centroid of the address components provided and does not reflect a specific address if the street address component is not provided."). It is not SLAM's geocode. A license with no point has no link.

Hours and method of operation. The State does not publish them. None of SLA's three open datasets (active, pending and inactive licenses) has a column for method of operation or hours (column lists checked on 2026-11-07), and neither did the LAMP popup when we checked (2026-11-04). SLAM does not copy them from other pages. Approval conditions for contested applications, which can include closing hours and community board stipulations, appear in the minutes of SLA's Full Board meetings; each meeting's page in the SLA event calendar links its minutes once they are posted after the meeting.
